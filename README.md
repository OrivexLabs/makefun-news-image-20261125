A one-page newspaper front page that sums up Wednesday 25 November 2026's
world news in ten stories — from Kyiv's confirmed strike on the Russian ship
Sparta II to the Houthi drone attack on Riyadh's PIF tower, the Huawei
verdict, China's probe of Chen Jining, tariff fears sinking Asian stocks,
Nvidia's fading rally, Senegal winning back the Africa Cup, Thailand's flood
emergency, and the Thanksgiving turkey pardon. Drawn in pure Python 3.13
standard library (no third-party code, no network): a 5x7 bitmap font,
geometric pictograms, and a hand-rolled PNG encoder. Deterministic — every
run writes byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
